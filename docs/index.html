2. Năm đặc tính điện toán đám mây NIST

1. On-demand self-service

Người dùng có thể tự tạo môi trường Codespace thông qua GitHub mà không cần yêu cầu quản trị viên cấp máy chủ.

2. Broad network access

API Hello Cloud được truy cập qua URL HTTPS từ máy tính và điện thoại sau khi cấu hình Port Visibility thành Public.

3. Resource pooling

GitHub sử dụng hạ tầng tài nguyên dùng chung để cung cấp môi trường máy ảo cho nhiều người dùng khác nhau.

4. Rapid elasticity

Người dùng có thể khởi tạo, dừng và khởi chạy lại Codespace. Cấu hình tài nguyên có thể được lựa chọn hoặc điều chỉnh theo nhu cầu sử dụng.

5. Measured service

GitHub theo dõi mức sử dụng tài nguyên thông qua Billing Usage, bao gồm compute usage tính bằng core-hours và dung lượng lưu trữ.

3. Kết luận

Qua bài thực hành, em đã tạo thành công môi trường lập trình trên GitHub Codespaces, xây dựng API Hello Cloud bằng Node.js và Express, đồng thời truy cập API từ thiết bị di động thông qua Internet.

Bài thực hành giúp em nhận diện năm đặc tính của điện toán đám mây theo NIST, hiểu cách đo lường tài nguyên và phân biệt môi trường lập trình trên máy cá nhân với môi trường trên nền tảng đám mây.
